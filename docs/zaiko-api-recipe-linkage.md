# 【改修依頼】在庫調整APIのレシピ連動対応（applyRecipe フラグ）

- 依頼元: みそ熟成・仕込み計画管理システム（miso-system）
- 依頼先: zaiko.mitsuura.jp 開発者
- 依頼日: 2026-07-06
- 対象: 在庫調整API（`STOCK_ADJUST_API_URL` に設定されている POST エンドポイント）

---

## 背景

みそ熟成管理システムからロット登録すると、在庫調整API経由で半製品（例:【半製品】無添加麦みそ（熟成中））の在庫数量が加算されるようになっています。

一方、zaikoの画面から手入力で在庫登録する場合は、品目に登録された**レシピが展開され、原材料（裸麦・大豆・並塩・種麹・A重油など）が自動で減算**されます（「在庫のみ変更（レシピ連動なし）」のチェックを外した状態の動作）。

現状、API経由の在庫加算ではこのレシピ展開が行われず、原材料在庫が減らないまま半製品だけが増えてしまいます。API経由でも手入力と同じくレシピ連動できるようにしてください。

## 依頼内容

在庫調整APIのリクエストボディに `applyRecipe` フィールド（boolean・任意）を追加し、以下の動作を実装してください。

| applyRecipe | 動作 |
|---|---|
| `true` | 手入力の在庫登録（レシピ連動あり）と同じレシピ展開処理を通し、`deltaKg` に応じて原材料在庫を増減する |
| `false` または未指定 | 従来どおり在庫数量のみ変更（後方互換） |

`applyRecipe: true` のときの原材料側の増減方向：

- `deltaKg` が**正**（在庫追加）→ 原材料を**消費（減算）**
- `deltaKg` が**負**（在庫減算）→ 原材料を**復元（加算）**。ロット誤登録の取り消しに使用します

## リクエスト仕様（変更後の全体）

```
POST ${STOCK_ADJUST_API_URL}
X-API-Key: （既存の EXTERNAL_API_KEY を共用）
Content-Type: application/json

{
  "misoType":    "無添加麦みそ" | "田舎みそ" | "山吹みそ" | "白みそ",
  "category":    "wip" | "aged",   // wip=熟成中（半製品）、aged=熟成済
  "deltaKg":     number,           // 正=追加、負=減算
  "lotNumber":   "202506-001",     // 参照用ロット番号
  "notes":       string,           // 任意。在庫変更履歴の備考列に追記
  "applyRecipe": boolean           // ★今回追加。true=レシピ連動あり
}
```

レスポンスは従来どおり HTTP 200 で成功とみなします。

## みそ熟成管理システム側の送信パターン（実装済み）

| 操作 | category / deltaKg | applyRecipe | 理由 |
|---|---|---|---|
| ロット登録 | wip / **＋**歩留まり重量 | **true** | 原材料を実際に消費している |
| 熟成完了 | wip / −、aged / ＋ | false | 半製品→製品の移動。原材料消費はない |
| 熟成中に戻す | aged / −、wip / ＋ | false | 同上（完了の取り消し） |
| ロット削除（熟成中） | wip / − | **true** | 誤登録の取り消し。原材料も復元する |
| ロット削除（完成済） | aged / − | false | — |

※ 白みそは熟成中品目がないため wip の呼び出しは行いません（従来どおり）。
※ `applyRecipe: true` は上記の2パターン（ロット登録・熟成中ロット削除）でのみ送信されます。

## リクエスト例

**ロット登録時（原材料を消費）**

```json
{
  "misoType":    "無添加麦みそ",
  "category":    "wip",
  "deltaKg":     1600,
  "lotNumber":   "202607-001",
  "notes":       "桶: 5・6 / 仕込み: 2026/07/06",
  "applyRecipe": true
}
```

期待動作:【半製品】無添加麦みそ（熟成中）を +1,600kg し、品目レシピに従って裸麦・大豆・並塩・種麹・A重油などを 1,600kg 相当分減算する。

**熟成中ロットの削除時（原材料を復元）**

```json
{
  "misoType":    "無添加麦みそ",
  "category":    "wip",
  "deltaKg":     -1600,
  "lotNumber":   "202607-001",
  "applyRecipe": true
}
```

期待動作:【半製品】無添加麦みそ（熟成中）を −1,600kg し、レシピ相当分の原材料を加算（復元）する。

## 補足

- みそ熟成管理システム側は対応済みで、すでに `applyRecipe` を送信しています。zaiko側が未対応の間はフィールドが無視されるだけなので、リリース順序の制約はありません。
- 原材料の変更履歴にも、可能であれば `notes` の内容（ロット番号・桶番号・仕込み日）を残していただけると、後からのトレースがしやすくなります。
- 動作確認は、テスト用の品種でロット登録→zaiko側で半製品＋原材料の両方が変動していること→ロット削除→両方が元に戻ることを確認すれば十分です。
